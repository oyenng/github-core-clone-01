A standalone GitHub-compatible git forge in a single Node process with zero dependencies: git smart HTTP (upload-pack protocol v2, receive-pack v0) for clone, fetch and push; the REST v3 API for repositories, issues, labels, contents and pull requests with squash merge; the GraphQL v4 API; and a Model Context Protocol endpoint — all served from its own store on a deterministic logical clock.

## Run it

```sh
node main.ts
```
